Měsíční a denní detail

Pokrytí RH = vlastní nenulová hodnota 1–100 % v jednoznačném UTC slotu. Nejde o ověření kalibrace. Nezpracované dny se nezapočítávají jako měřené.

Detail dne

MAE znamená průměrnou absolutní odchylku v procentních bodech RH. Vypočtena pouze tam, kde byla vlastní RH a spárovaná referenční RH. Není-li dost párů, není to spolehlivý důkaz přesnosti reference.

Metodika

Čas: UTC, 288 pětiminutových slotů na den. Reference mají stav reference_only, relativní vlhkost v intervalu 1–100 % a čas blízký slotu nejvýše ±30 sekund; duplicity se vylučují. Hodnoty RH = 0 %, záporné a nad 100 % se nepovažují za použitelné. Kandidát ke kontrole vznikne jen při existujícím původním řádku s NULL RH a při rozdílu obou referencí nejvýše 10 procentních bodů. To není automatické nahrazení hodnot. Soukromé denní JSON obsahují jednotlivé časy referenčních podkladů, tento přehled jen statistiky.
